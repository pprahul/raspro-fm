Abstract

Self-supervised Foundation Models (FMs) for electrocardiogram (ECG) and photoplethysmogram (PPG) waveforms rely predominantly on fixed-duration signal patching (ST-MEM, MaeFE), vector-quantized heartbeat codebooks (HeartLang), or Gaussian symbolic subwords (ECG-Byte). Despite strong accuracy on massive archives, these paradigms suffer from three structural bottlenecks: (1) severe temporal redundancy on stationary sinus rhythm, inflating quadratic O(L²) Transformer attention compute; (2) physiological blindness to low-amplitude clinical landmarks (e.g., ST-segment shifts, PR delays, pathological Q-waves, dicrotic notch blunting) under z-normalization; and (3) low-data fragility under random subsampling. Building on our research team's prior work on Rapid Active Summarization for Effective Prognosis (RASPRO) for data-efficient smart-edge prognostic models, we extend the RASPRO framework to pre-train multi-layer Biosignal Foundation Models (RASPRO-FM). RASPRO synchronizes to cardiac R-peaks, quantizes 9-slot 12-lead anatomical and 6-slot multi-sensor parameters into a clinical severity alphabet Σ = {A, B, N, Y, Z} via Physician Assist Filters (PAF), summarizes multi-beat windows into Consensus Motifs (CM) and Consensus Abnormality Motifs (CAM), and run-length merges stationary segments. We pair RASPRO with a 72-D Compositional Slot-and-Pair Subspace, a CMI-Biased Multi-Layer Transformer, and Criticality Measure Index (CMI) Submodular Coreset Selection. Across PhysioNet PTB-XL, cross-hospital MIMIC-IV-ECG, and PhysioNet BIDMC ICU streams, RASPRO-FM reduces O(L²) attention compute by 50×–2,215× (1,797× vs. ST-MEM), reaches 79.79% Superclass and 79.08% 4-task Mean Macro-AUROC on PTB-XL Fold 10 (outperforming SimCLR, BYOL, MaeFE, MERL, CLOCS, and ST-MEM), transfers zero-shot across hospitals (78.06% AUROC), and achieves 10×–20× pre-training data efficiency.
RASPRORapid Active Summarization for Effective Prognosis

Transforms high-frequency multi-sensor physiological streams into compact, clinically interpretable motif sequences.

PAFPhysician Assist Filters

Quantizes calibrated physiological slots into a 5-level clinical severity alphabet Σ = {A, B, N, Y, Z}.

SSM / MSMSingle-Sensor / Multi-Sensor Matrix

Beat-synchronous 9-slot 12-lead ECG anatomical matrix and 6-slot coupled ICU multi-sensor (ECG+PPG+RESP) matrix.

PHM (CM / CAM)Personalized Health Motifs

Separates stationary homeostatic windows into Consensus Motifs (CM) and acute excursions into Consensus Abnormality Motifs (CAM).

CMICriticality Measure Index

Continuous urgency score [0, 1] that biases multi-head Transformer attention and guides submodular coreset selection.

72-D SubspaceCompositional Slot-and-Pair Prior

Eliminates vocabulary sparsity across 5.86M motif combinations via signed slot polarity and 36 pairwise cross-lead interactions.

Tokenization Paradigm & RASPRO-FM Architecture

Figure 1: Biosignal Tokenization Comparison on a 10-Second Clinical ECG Strip. Continuous Patching and Vanilla SAX emit L=25–150 fixed-clock tokens; ECG-Byte merges frequent subwords (L=20); HeartLang emits one VQ token per heartbeat (L=13.6); RASPRO summarizes 4-beat windows into Consensus Motifs (CM) and Consensus Abnormality Motifs (CAM) and run-length merges stationary normal runs into just L=3.54 active tokens (50×–1,797× fewer O(L²) attention FLOPs).
Figure 2: End-to-End RASPRO-FM Architecture. Four-stage pipeline combining (1) Beat-Synchronous 9-Slot 12-Lead & 6-Slot ICU Multi-Sensor Feature Extraction with Physician Assist Filters (PAF), (2) Hierarchical MSM → CM/CAM Summarization & Active Deduplication, (3) 72-D Compositional Slot-and-Pair Subspace + 4-Layer CMI-Biased RASPRO-Transformer FM, and (4) Two-Stage Hierarchical CMI Submodular Coreset Selection.

Quickstart & 1-Command Reproducibility

The repository includes pre-tokenized lightweight .npz hospital caches (data_cache/ptbxl_hospital_1600_300_400.npz at 871 KB and data_cache/mimic_iv_ecg_stream_160.npz at 59 KB) so all benchmarks run out-of-the-box without requiring multi-gigabyte PhysioNet downloads: 

git clone https://github.com/pprahul/raspro-fm.git
cd raspro-fm/raspro-ecg-fm
pip install -e .

# 1. Run Multi-Layer GPU/MPS RASPRO-Transformer FM on PTB-XL Fold 10 + Zero-Shot MIMIC-IV-ECG Transfer
python scripts/run_phase4_full_hospital_transformer.py

# 2. Run Controlled 12-Lead Tokenizer Ablations (Patch, SAX, ECG-Byte, HeartLang-QRS, RASPRO 6/8/9-Slot)
python scripts/run_phase3_ptbxl_sota_benchmark.py

# 3. Run Real-World Multi-Sensor ICU Telemetry Benchmark (PhysioNet BIDMC ECG + PPG + RESP)
python scripts/run_phase2_physionet_benchmark.py

# 4. Run Coupled ECG + PPG Biophysical Data-Scaling Benchmark (5% to 100% Coreset Pruning)
python scripts/run_scaling_benchmark.py
